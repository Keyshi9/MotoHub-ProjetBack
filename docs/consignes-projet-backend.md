## 3. Descriptif du projet

- Le but de ce projet est de créer une **API**.
- L'API devra permettre de gérer **toutes les données** utilisées dans le projet (**CRUD**).
- Les technologies sont celles étudiées durant le **module 295** (**Node.js**, base de données **MySQL**).
- Le groupe de travail est constitué de **1 à 4 membres**. Les groupes sont constitués librement.
- Chaque membre du groupe a la charge d'**au moins une entité** et de la gestion de ses données. Le modèle de données comprend donc au moins 4 entités si le groupe compte 4 membres.
- La **méthode agile** est utilisée pour gérer le projet. Le nombre de sprints nécessaires est à définir. L'outil utilisé est **GitHub Project**.
- L'IA peut être utilisée comme une aide et pour résoudre des éléments ponctuels, mais **ne doit en aucun cas écrire le code ou réfléchir à la place de l'étudiant**.

## 5. Points techniques

- Chaque fichier aura un **en-tête rempli**.
- Le code doit être **correctement commenté**.
- Le code doit respecter les **conventions de nommage du langage** et les **conventions du CPNV** concernant la modélisation de la base de données.
- Les **cas d'erreur** doivent être traités : messages d'erreur, pas de bug bloquant.
- L'API sera **sécurisée** (gestion d'un token).
- Il est possible de **générer une documentation de l'API** à partir des commentaires dans le code.
